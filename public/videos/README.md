# Promotional & Showcase Videos

This directory stores exported video assets for the portfolio.

## Creative Asset Requirements (Adobe After Effects)
- **Target File**: `portfolio-intro.mp4`
- **Format**: MP4 (H.264 video codec, AAC audio codec)
- **Duration**: Between 30 and 60 seconds
- **Resolution**: 1080p (1920x1080) or 4K, optimized for web streaming (fast-start / web-optimized moov atom).
- **Source Project**: Keep the original After Effects project file (`Portfolio_Intro.aep`) preserved in project archives or project root for subsequent editing.
